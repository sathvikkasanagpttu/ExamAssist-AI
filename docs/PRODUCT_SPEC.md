# Product Specification

## Product name
ExamAI Study Assistant

## Core features
- Copy-to-answer workflow
- Visible on-page answer panel
- AI-generated explanations
- Search-backed evidence
- Source links
- Confidence/verification status
- Settings page
- Local backend architecture
- Privacy-conscious API-key handling

## Future features
- PDF/lecture-note ingestion
- OCR for screenshots used in study mode
- Flashcard generation
- Citation export
- Math verification
- Code execution sandbox
- Personal study history
- Teacher/admin mode
- Institutional deployment controls

## Non-goals
- Hidden screen-share behavior
- Bypassing exam proctoring
- Guaranteeing 100% accuracy
- Scraping every website on the internet
- Concealing AI use from an institution that prohibits it
