## 4. How to Generate & Populate Verified Live Reports

To record a genuine live evaluation run into this report:

```bash
cd server

# 1. Ensure real API key and Docker sandbox are running
export OPENAI_API_KEY="your-real-key"
docker compose up examassist-sandbox -d

# 2. Run live academic evaluation (generates verified result JSON with hash and runId)
node eval/runner.mjs --config a_single_pass

# 3. Run live coding evaluation (requires live AI + Docker sandbox; refuses to run simulated)
node eval/code-runner.mjs --ablation 4_plus_diff_property

# 4. Verify gate against recorded live baseline
npm run eval:gate
```
